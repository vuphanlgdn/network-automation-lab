# 🌐 Network Automation Lab

Practical network automation experiments using **Python, Ansible, MikroTik and Cisco**.

This repository documents hands-on network automation labs, scripts, configurations, and troubleshooting techniques.

## 🎯 Objectives

* Automate common network administration tasks
* Learn Python for network automation
* Practice Ansible automation
* Automate MikroTik and Cisco configuration
* Create reusable network administration scripts
* Document real-world infrastructure problems and solutions

## 🧰 Technologies

* Python
* Ansible
* MikroTik RouterOS
* Cisco IOS
* Linux
* SSH
* YAML

## 🧪 Labs

### Lab 01 — Network Device Discovery

Use Python to test connectivity to multiple network devices.

**Skills:**

* Python
* ICMP
* IP addressing
* Network troubleshooting
* Automation

### Lab 02 — SSH Device Information

Connect to network devices through SSH and collect basic information.

### Lab 03 — Automated Configuration Backup

Automatically collect and store device configurations.

### Lab 04 — MikroTik VLAN Automation

Automate VLAN configuration and verification.

### Lab 05 — Cisco VLAN Automation

Automate VLAN configuration using Ansible.
